# Contributing to eeFunction Site

Thank you for improving the public eeFunction product website.

## In scope

Contributions are welcome for:

- website copy and factual corrections;
- Korean and English translations;
- accessibility and responsive-layout improvements;
- public product information and compatibility tables;
- example catalogue metadata and presentation;
- documentation links, navigation, and search;
- test coverage and build reliability;
- non-sensitive design-system components.

## Out of scope

This repository does not accept contributions to:

- the proprietary eeFunction calculation engine;
- license verification or payment-bypass mechanisms;
- private test data or customer workbooks;
- signing keys, deployment credentials, or production secrets;
- undocumented claims about numerical accuracy or standards compliance.

## Before opening a pull request

1. Search existing issues and pull requests.
2. Open an issue for significant information-architecture or branding changes.
3. Keep each pull request focused on one clear purpose.
4. Do not include customer data, confidential calculations, or licensed third-party material.
5. Cite authoritative references for technical, compatibility, security, or standards-related claims.
6. Confirm that screenshots contain no personal information, workbook secrets, or license identifiers.

## Content standards

Product content must distinguish clearly between:

- released, preview, planned, and proposed functionality;
- Free, Pro, Team, and Enterprise capabilities;
- official, verified, community, and unreviewed examples;
- local calculation and server-side processing;
- product compatibility and general Office Add-in platform capability.

Do not publish performance, accuracy, or security claims without traceable evidence.

## Pull request expectations

A pull request should explain:

- what changed;
- why the change is needed;
- which pages or users are affected;
- how the change was tested;
- whether new copy requires legal, technical, or product review.

By contributing, you confirm that you have the right to submit the material under the repository license and that the contribution contains no confidential information.
