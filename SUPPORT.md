# Support

This repository is the public source for the eeFunction product website. It is not the primary channel for urgent commercial support.

## Use GitHub issues for

- reproducible website defects;
- broken links or inaccurate public content;
- accessibility problems;
- missing or incorrect example catalogue metadata;
- public documentation integration problems.

## Use GitHub discussions for

- general product questions;
- proposed website content;
- community example ideas;
- non-urgent feature suggestions;
- feedback about product positioning or usability.

## Do not use public channels for

- security vulnerabilities;
- license keys, invoices, or payment details;
- private workbooks or customer data;
- confidential engineering calculations;
- credentials or deployment secrets.

Follow [SECURITY.md](./SECURITY.md) for sensitive security reports.

## Product support status

Formal support tiers, service targets, supported versions, and commercial contact channels will be published before the eeFunction Pro general-availability release.
