# Content Plan

## Launch priority

### Tier 1: required for public Pro launch

1. Home page with a concrete product definition
2. Pro overview and Free versus Pro comparison
3. Pricing, trial, or procurement path
4. Ten official Excel examples
5. Function catalogue entry points
6. Compatibility matrix
7. Security and data-handling page
8. Installation and support links
9. Release notes and known issues
10. Company and legal information

### Tier 2: credibility and adoption

- industry solution pages;
- customer or internal use cases with permission;
- validation methodology;
- migration guide from Free to Pro;
- tutorial index;
- community example submission guide;
- roadmap and request process.

### Tier 3: growth content

- technical articles;
- comparison and migration content;
- engineering templates;
- webinars and demonstration videos;
- partner and educational content.

## Homepage narrative

1. Define the product in one sentence.
2. Show the add-in operating inside Excel.
3. Explain user outcomes rather than only function counts.
4. Present representative engineering workflows.
5. Demonstrate official examples and validation information.
6. Compare Free and Pro.
7. Explain data handling and supported platforms.
8. Present pricing or trial action.

## Example quality standard

Each official example should include:

- problem statement;
- inputs and assumptions;
- functions used;
- workbook preview;
- result interpretation;
- applicable range and limitations;
- validation source and status;
- compatible platforms and minimum version;
- downloadable workbook;
- revision history.

Community examples must be visually distinguished from official verified examples.

## Copy rules

- Avoid unsupported superlatives such as “most accurate” or “industry standard.”
- Do not describe planned functions as available.
- Use exact function names and product versions.
- Explain units and engineering assumptions.
- Separate platform support from function-specific support.
- Distinguish local processing from any network-dependent operation.
- Include a review date on security, compatibility, and legal pages.
